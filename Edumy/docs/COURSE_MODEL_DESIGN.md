# Model Design Specification — Course Classification

This document specifies the architectures and optimization procedures designed for the Course Classification task.

---

## 1. Classifiers

### Model A: Linear SVM
- **Algorithm**: `LinearSVC` (Support Vector Classifier with a linear kernel).
- **Justification**: Highly effective for sparse high-dimensional data generated by TF-IDF vectorizers.
- **Probability Calibration**: Wrap in `CalibratedClassifierCV` using Platt scaling (sigmoid calibration) to compute proper confidence scores for the Admin monitoring dashboard.

### Model B: Multi-Layer Perceptron (MLP)
- **Architecture**: A feedforward neural network built with TensorFlow/Keras:
  ```
  Input Features (5,000 dense TF-IDF values)
                       │
                       ▼
             [ Dense (512, ReLU) ]
                       │
                       ▼
                [ Dropout (0.3) ]
                       │
                       ▼
             [ Dense (256, ReLU) ]
                       │
                       ▼
                [ Dropout (0.3) ]
                       │
                       ▼
             [ Dense (128, ReLU) ]
                       │
                       ▼
                [ Dropout (0.2) ]
                       │
                       ▼
             [ Dense (4, Softmax) ] (For 4 subjects)
  ```
- **Loss**: `SparseCategoricalCrossentropy`
- **Optimizer**: `Adam` (initial learning rate `1e-3`)
- **Callbacks**: `EarlyStopping` (patience=5), `ReduceLROnPlateau`

---

## 2. Split & Class Imbalance
- **Split Ratio**: 70% Train, 15% Validation, 15% Test.
- **Stratified Split**: Preserve subject ratios across all folds.
- **Class Imbalance**: Pass computed class weights (`class_weight`) to the optimizer during training. Do not use SMOTE.
